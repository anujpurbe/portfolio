## 📖 Overview

This repository contains the source code for my personal engineering portfolio. Built using Next.js 14, TypeScript, and Tailwind CSS, it features high lighthouse performance, responsive layout across all device viewports, dark mode aesthetic, and smooth micro-animations.

---

## ✨ Features

- 🎨 **Modern Design:** Glassmorphic dark aesthetic with cohesive typography and subtle motion.
- 📱 **Fully Responsive:** Seamlessly adapted for desktop, tablet, and mobile screens.
- ⚡ **Optimized Performance:** Fast load times powered by Next.js Server Components & static optimization.
- 🛠️ **Project Showcase:** Highlights flagship projects including Hiingers, Atomic Battery Analysis, and FoodieHub.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (React)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

---

## 🚀 Quick Start & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anujpurbe/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.
